# Working rules

- Get the owner's confirmation before making any change: editing, creating or
  deleting files (including generated files and temporary config), committing,
  pushing, or posting anything on GitHub.
- Before starting a task, restate the assignment and the planned approach, and
  wait for the owner to confirm it was understood correctly. Ask when unsure
  instead of guessing.
- Reading and inspecting the code without changing anything is fine without
  asking.
